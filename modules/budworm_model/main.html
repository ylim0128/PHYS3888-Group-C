Budworm population model

Noisy non-dimensional budworm dynamics, integrated with Euler-Maruyama: dx = [r x (1 - x/k) - x²/(1 + x²) + h] dt + σ dW, with k = 10, x ≥ 0 and x(0) = 0. The control parameter r carries the system towards a fold (saddle-node) bifurcation; h is an imperfection.

Task: each row is one 200-sample run at its own r. Label 1 if r is within 0.04 below the lower fold (r ≈ 0.384 for h = 0, ≈ 0.364 for h = 0.05); Label 0 if r is at least 0.15 further below it.

Label 1 (near) Label 0 (far). One example row each, per condition:

h = 0.0; parameter fixed during the row

Imperfect bifurcation (h=0.05)

h = 0.05; parameter fixed during the row

Variable noise (h=0)

h = 0.0; parameter fixed during the row; noise grows near the critical point

Fast sweep (h=0)

h = 0.0; parameter drifts during the row

Notes

  • Folds are located numerically from the fixed-point curve, not hard-coded.
  • The first 500 steps of every run are discarded as transient.
  • In the sweep condition r drifts at 5e-3 per time unit (Δr = 0.1 across the row).
  • With h = 1 the fold disappears entirely, so the imperfect condition uses h = 0.05.
  • In the variable-noise condition σ rises from 0.3 to 1 at the fold, so noise amplitude alone reveals the label.
