FitzHugh-Nagumo neuron

Noisy FitzHugh-Nagumo model, integrated with Euler-Maruyama: dv = (v - v³/3 - w + I) dt + σ dW, dw = ε (v + a - b w) dt, with a = 0.7, b = 0.8, ε = 0.08. Only the membrane potential v is recorded. Raising the input current I crosses a Hopf bifurcation from quiescence to spiking.

Task: each row is one 200-sample run (50 time units) at its own I. Label 1 if I is within 0.04 below the lower Hopf point (I ≈ 0.3313); Label 0 if I is at least 0.07 further below it, so the neuron is quiescent in both classes.

Label 1 (near) Label 0 (far). One example row each, per condition:

Variable noise

Fast sweep

parameter drifts during the row

Notes

  • The Hopf point is computed from the Jacobian trace, not hard-coded.
  • The first 1000 steps of every run are discarded as transient.
  • In the sweep condition I ramps at 2e-3 per time unit (ΔI = 0.1 across the row).
  • Near the bifurcation the noise drives a distinctive, weakly damped oscillation, so this task is easier than the budworm one.
