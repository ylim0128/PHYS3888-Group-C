Time Reversibility

Noise Processes

Gaussian noise: Gaussian distributed noise. Default x~N(0,1).

Uniform noise: Uniformly distributed noise. Default x~U(-0.5,0.5).

Pink noise: Pink noise with power density S(f) p.t. 1/f.

Red noise: Generated via an AR(1) process. Default a=0.9.

Violet noise: Violet noise with power density S(f) p.t. f^2. Generated by differentiating white noise.

Gamma noise: Gamma distribution noise. Default x~Gamma(1,0.3).

Laplacian noise: Laplacian distribution noise. Default x~Laplace(0,1).

Autoregressive models

AR(1) with Gaussian noise: First order autoregressive model AR(1). Default a=0.5.

Static trasformation of AR(1): AR(1) model with static transformation y=tanh^2(x). Default a=0.6.

AR(1) with uniform noise: Linear AR(1) model with uniformly sampled noise rather than Gaussian. Default again alpha=0.5.

ARMA(1,1) with uniform noise: Linear ARMA(1,1) model with uniformly sampled noise. Default alpha=0.6, theta=0.4.

AR(3) with gamma sampled noise: Third order autoregressive model AR(3) with gamma noise. Default a=0.1, b=0.2, c=0.3, x~Gamma(1,0.3).

SETAR(2;1,1,1): Self-exciting threshold autoregressive model SETAR(2;1,1,1), with two AR(1) regimes, switching controlled by the first delay paramater and both systems first order. Default a1=-0.9, a2=-0.4, theta=1, threshold x[t-1]=1.

SETAR(2;2,2,2): SETAR(2;2,2,2) model, with two AR(2) regimes, switching controlled by the second delay paramater. Defaults as given.

Nonlinear AR(2) with Laplacian noise: Nonlinear AR(2) process. Consists of various quadratic and sinusoidal terms as seen below. Defaults as given.

Deterministic chaotic maps

Arnold's Cat map: Arnold's Cat Map of the form x[t+1] = a1x[t] + b1y[t] mod n, y[t+1] = a2x[t] + b2y[t] mod n. Defaults as given. Consider by default the x component if use_x=True, y component is use_x=False.

Chirikov standard map: Chikrov standard map of the form theta[t+1] = theta[t] + p[t] + K/2pi sin(2pi theta[t]) mod n, p[t+1] = theta[t+1] - theta[t] mod n. Consider p component by default, theta if use_p=False.

Quadratic map: Quadratic map with scaling factor a of the form x[t+1]=1-ax[t]^2.

Chaotic logistic map: Logistic map with R=4, which lies in the fully chaotic regime.

intermittent logistic map: Logistic map with R=3.8284, which lies in the period-3 window, where it exhibits intermittency.

Other deterministic models

Linear model with logistic noise: Linear model x[t+1] = ax[t] + epsilon[t] with deterministic logistic noise source epsilon[t] = 4*epsilon[t-1](1-epsilon[t-1]).

Modulo-1 model: Modulo-1 model x[t] = ax[t-1] mod 1

Linear oscillator: Linearised oscillator with dynamics described by d^2x/dt^2 + x = 0, y = dx/dt, dy/dt=-x.

Mackey-Glass model: Mackey-Glass temporal delay equation, given by dx/dt = (beta0*x(t-tau))/(1+x(t-tau)^n) - gamma*x(t).

Other stochastic processes

Ornstein-Uhlenbeck process: Ornstein-Uhlenbeck process given by dx = -theta*xdt + sigma*dW, where W is a Weiner process.
